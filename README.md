Alpha do jogo Sunborn para a matéria de XP6

Instruções para rodar o projeto no editor da Unity em windows 11:
Sem acesso a versionamento:
1. Abra o repositório do projeto no github.com
2. Clique no botão verde "Code" e clique em "instalar ZIP"
3. Extraia o arquivo do projeto em uma pasta separada no Explorador de arquivos
4. Abra o Unity Hub
5. Clique em adicionar projeto no disco
6. Escolha a pasta My-Project
