Alpha do jogo Sunborn para a matéria de XP6

https://github.com/GabrielDyas/XP-6-7.git

Vídeo técnico da Alpha: https://youtu.be/BXqoaakk7Uk

Instruções para rodar o projeto em Windows 11/10:
1. Abra o repositório do projeto no [github.com](https://github.com/GabrielDyas/XP-6-7.git)
2. Clique no botão verde "Code" e clique em "instalar ZIP"
3. Extraia o arquivo do projeto em uma pasta separada no Explorador de arquivos
4. Abra a pasta Game e execute Sunborn.exe

Instruções para rodar o projeto no editor da Unity em Windows 11/10:

O que precisa:

Unity Hub - 
Unity editor versão 6000.6.0f1

Hardware:

Teclado QWERTY e Mouse

Sem clonar o repositório diretamente:
1. Abra o repositório do projeto no [github.com](https://github.com/GabrielDyas/XP-6-7.git)
2. Clique no botão verde "Code" e clique em "instalar ZIP"
3. Extraia o arquivo do projeto em uma pasta separada no Explorador de arquivos
4. Abra o Unity Hub
5. Instale o editor versão 6000.6.0f1 no arquivo ou manualmente no link [archive](https://unity.com/releases/editor/whats-new/6000.6.0f1#installs)
6. Clique em adicionar projeto no disco
7. Escolha a pasta (...)\My-project\XP6
8. Escolha o editor 6000.6.0f1
9. Abra o projeto

Clonando o repositório via aplicativo:
1. Instale [Github Desktop](https://desktop.github.com/download/)
2. Abra o aplicativo e clique em "Clone repository" ou aperte Ctrl + Shift + O
3. Cole o link do repositório "https://github.com/GabrielDyas/XP-6-7.git"
4. Repita a etapa 4 a 9 das instruções anteriores


Instruções para jogar o jogo:
WASD: Controla o movimento do player

Espaço: Pular e Pulo duplo quando está no ar

Shift + A/S/D: Dash

Shift + W: Correr

Q: Habilidade Vórtice

E: Habilidade Bola de energia (não funcional na build atual)

Botão esquerdo do mouse/MB1: Atirar

R: Recarregar

AVISO: Ambos os integrantes utilizaram de IA generativa do Chat GPT e Gemini para correção dos códigos
